# 视觉与设计规范 (Design Spec)

## 核心视觉原则
1. **风格:** 自然、低模 (Low-poly)、3D卡通、低饱和、清晰。绝对禁止光污染、Bloom、过度的霓虹灯效以及写实风格。
2. **光影:** 明亮的全局光照，柔和的阴影。环境光充足，不依赖大量的点光源。
3. **透视:** 
   - 屏幕比例：9:16 (竖屏)。
   - 摄像机俯角：35~55度向下俯视。
   - 机器位置：保持在屏幕下方 35% ~ 42% 的区域。

## 配色方案 (Color Palette)
- **地面:** 浅灰/浅蓝/浅绿 (根据不同区域变化)。
- **黑洞:** 
  - 中心：纯黑 (`#000000`)，高粗糙度，无反光。
  - 边缘：青色发光边缘 (Cyan/Light Blue)。
- **垃圾/资源:**
  - 采用清晰的单色块：红色、黄色、蓝色、绿色等低饱和度色彩。
  - 不同 Tier 等级有明显的体积与色彩区分。
- **UI:** 白色/灰色半透明底板，黑色/深色文字，无边框或极简圆角边框 (非重度 MMO UI)。

## 机器进化阶段 (5 Stages)
1. **LV1 (基础黑洞车):** 四个轮子 + 扁平底盘 + 核心黑洞。
2. **LV2 (双涡轮风扇):** 增加两侧的绿色/橙色涡轮，增加吸力范围。
3. **LV3 (冲压粉碎机):** 增加前方/上方的机械冲压结构，用于碎裂大型垃圾。
4. **LV4 (反重力翼):** 去除轮子，增加两侧的悬浮侧翼，地面有微光。
5. **LV5 (奇点光环):** 核心黑洞扩大，外部环绕发光的奇点光环，处于全屏吸入状态。

## 场景结构 (World Chunks)
- **尺寸:** 开放式空间，每个区域至少 24m 宽，30~40m 长。
- **序列 (RegionSequence):**
  1. Bedroom (卧室)：床、书桌、玩具、书籍。
  2. Warehouse (仓库)：木箱、铁桶、托盘、推车。
  3. Supermarket (超市)：货架、罐头、购物车、纸箱。
- 玩家可向任意方向 360 度移动，没有绝对的墙壁限制，到达边界会自动生成新区块。
