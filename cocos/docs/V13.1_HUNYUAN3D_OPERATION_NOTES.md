# 混元3D 实际操作笔记（2026-10-20）

## 已验证的界面事实（内置浏览器实测）

**URL**: https://3d.hunyuan.tencent.com/sceneTo3D

**四种模式**（radio，DOM 是 `input[type=radio]`）：
1. 世界生成（文字）
2. 世界重建（图+文字）
3. 360°全景图
4. 实时生世界

### DOM 结构与坑（重要，下次直接用）

| 元素 | 选择器 | 状态 |
| --- | --- | --- |
| 模式单选 | `input[type=radio]` × 4 | DOM 存在，**Playwright click 报 hidden**（被上层遮挡），需 evaluate 触发 |
| 提示词输入 | `textarea.t-textarea__inner` | `disabled=false`，但 `visibility:hidden` + `pointer-events:none`，**Playwright fill 报 hidden**；必须用原生 setter |
| 图片上传 | `input[type=file]` | accept `.png,.jpg,.jpeg,.webp` |
| 字数统计 | `.input-bar .text-length` | 显示 `256 / 600`（上限 600 中文字符） |
| 生成按钮 | **未找到** | input-bar 之后无兄弟元素，无 submit/generate class |
