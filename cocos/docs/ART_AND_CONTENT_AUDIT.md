# ART AND CONTENT AUDIT

Answers two questions with evidence rather than assurance: **did the UI art actually
use Blender**, and **is the game content complete**. Run as a read-only sweep; the
commands to reproduce each section are at the end.

---

## 1. Did the UI use Blender? — Partly, and deliberately so

Two pipelines produced the shipped UI art, and which one made what is checkable from
the files rather than from memory.

### Blender-produced, and shipped

| Shipped asset | Blender script | Evidence |
| --- | --- | --- |
| `game_art/ui/v95/home_hero_blackhole.png` (1120x1120) | `art-source/blender/render_v95_assets.py` | the script renders `hero_blackhole.png` at 560x560 and `render()` multiplies by `SUPERSAMPLE`, so 1120x1120 is its output size; the shipped file is exactly that |
| the city band inside `game_art/ui/v95/home_field.png` (720x1280) | `art-source/blender/render_home_assets.py` renders `home_city_band.png` (1440x1280); `art-source/vector/compose_home_layers.py` composites it into the field | the composer reads `home_city_band.png` and writes `home_field.png` |

So **the hero black hole on every page that shows it, and the Home backdrop's city
band, are Blender renders.** Those are the two pieces of the UI with real 3D content
in them — a singularity with a rim and a rotating disc, and an isometric city strip —
which is what Blender is for.

### Vector/PIL-produced, and shipped

Everything else in `game_art/ui/v95/`: the brand plate, the yellow and purple
capsules, the mode cards and their frames, the settlement board and ribbon, the
panels, badges, the reward bar, the local row. Plus the three stat icons and the
card plinth added this cycle. These are flat shapes with outlines and gradients,
generated by `art-source/vector/*.py`.

That split is a choice, not a shortfall: rendering a rounded rectangle in Blender
would add a 3D pipeline to a 2D shape and produce a worse one. The brief's
requirement was to *produce and integrate real art* rather than re-position old
components, and that is what the vector pipeline does.

### Blender itself

- Installed: `C:\Program Files\Blender Foundation\Blender 4.5`, and a second copy at
  `C:\Users\zyu33\tools\blender-4.5.14-windows-x64`.
- `bpy` is not importable from the system Python, which is expected — Blender ships
  its own interpreter, and the scripts are run through it.
- Scripts: `render_v95_assets.py` (UI dioramas and the hero), `render_home_assets.py`
  (hero + city band), `probe_glb_render.py` (GLB inspection), `_tiletest.py`.
- Both scripts carry the traps found while writing them: node lookup by
  `node.type == 'BSDF_PRINCIPLED'` rather than by name (names differ across versions
  and UI languages), `bpy.context.view_layer.update()` before reading `matrix_world`,
  and a textureless-GLB guard that checks `image.size == (0, 0)` rather than
  `has_data`.

### Superseded Blender output

`hero_blackhole.png`, `city_band_home.png` and `card_vignette_*.png` from
`render_v95_assets.py` are **not** referenced by any scene, prefab or script and were
moved to `art-source/inputs/` during the package-size work. The shipped hero is a
later take of the same subject at the same size, so this is a superseded render, not
lost art — the earlier note that the shipped hero might be `render_home_assets.py`'s
560x560 output was wrong: that size does not match the shipped file.

### Coverage gates, all passing

| Gate | Result |
| --- | --- |
| `npm run audit:object-art` | **PASS** — every collectible type resolves to authored art |
| `npm run verify:machine-archive` | **PASS** — the archive page and the Kit progress bar both read the save |
| `npm run verify:audio` | **PASS** — 7 declared clips resident, effects play, muting silences them |
| `npm run verify:layout` | **PASS** — 8 pages x 3 viewports |
| `npm run verify:gameplay-visuals` | **PASS** — Endless and Arena, hero findable |

### Content that is deliberately absent

Each of these was checked against the product's own rules rather than assumed to be a
gap:

- **No shop, no ads, no daily reward, no lucky wheel, no friends, no mail, no
  titles.** The design manifest lists all of them as `forbiddenElements`, and the
  Home page correctly omits the reference's icon rails and tab bar.
- **No public real-player matchmaking.** Arena is local players plus AI, and is
  described that way in the UI (`1v7 本地竞技 · 已开放`). Advertising it as public
  matchmaking is explicitly forbidden by the brief.
- **No settings page**, but the sound toggle that matters now lives on Pause.
- **No vibration control**: `settings.vibration` has a persisted setter but no
  consumer, so no switch was added rather than shipping one that does nothing.
- **No music track.**
- **Six of seven sound cues are provisional synthesis**, not licensed recordings;
  provenance and the reason the library cues were not swapped in blind are in
  `AUDIO_PROVENANCE.md`.
