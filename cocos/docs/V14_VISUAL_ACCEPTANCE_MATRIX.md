## 逐状态记录

### mode（PASS）
两张卡都是城市街区小景 + 黑洞，文案由 Label 绑定（不在图里）。竞技/无尽同一套视觉语言
（白天/黄昏）。三档布局一致，文字不压建筑。

### endless_moving（PASS）
玩家黑洞在路面中央、可辨认；`+50 / +60` 吞噬反馈可见；HUD 显示
`LV.1 初级黑洞 / 质量 155kg / 下一级 磁力黑洞`；行道树、车辆、斑马线都在。
**读得懂"我在吃、我在长"。**

### arena_mid / arena_chase（P1）
建筑在路两侧成排、颜色有变化、可吞物（纸箱/木箱）清晰可辨，HUD 完整。

**P1 缺陷：街区内部是大片草地。**
- 影响：场景构图（25 分项）。读起来像"建在草地上的城市"，而参考图的街区内部是
  铺装广场/停车场/水渠。
- 证据：`arena_mid-390x844.png`、`arena_chase-390x844.png`
- 为什么没当场修（路径受限，不是偷懒）：
  1. 地面颜色是**全局按 kind**（`WORLD_PALETTE.terrainTile`），所有城区共用，
     改成铺装会把公园街区也变灰；
  2. `path-stones-long.glb` 在 `Supermarket.prefab` 里**引用数 0**，要用它就得手写
     MeshRenderer 的网格引用——指令禁止手工伪造序列化 UUID；
  3. 用现有 `road-straight` 克隆当停车场：图集含斑马线，放大后是巨型条纹。
- 两条可执行方案：
  - **A（推荐）**：给 `terrainTile` 增加按主题的地面变体（如 `terrainTilePaved`），
    由 `DistrictTemplates` 按区域选择。一次解决六个城区的地面语言，是真实功能改动。
  - **B**：通过 Creator 编辑器把 `path-stones-long` 引入为可克隆的地面道具（需编辑器会话）。
