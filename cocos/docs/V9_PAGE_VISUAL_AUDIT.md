## 逐页审查

### Home — 浅色
- **PRIMARY ACTION**：`开始吞噬`（金色 CTA），位置在画面下三分之一、视觉重量最大 ✓
- **一眼看哪里**：黑洞本体（带皇冠）→ 金色 CTA ✓
- **可删**：无。顶部 `金币 0` 与 `初级黑洞 LV.1` 是必要状态。
- **需要强调**：已经是 CTA 最亮，无需调整。
- **Panel 是否必要**：无多余 Panel，三个入口按钮（模式/机器/皮肤）各自承担导航 ✓
- **Placeholder 感**：无。背景是真实 3D 世界。
- **同一款游戏**：✓ 金 CTA + 紫/绿/蓝入口按钮，与其它页一致。
- **备注**：`皮肤` 按钮美术自带锁图标。已确认 Home 下**没有独立的锁节点**，所以它是该分类的图标（与 `模式` 的胶片、`机器` 的机器图标并列），**不是"未解锁"提示**。不改。

### ModeSelect — 浅色
- **PRIMARY ACTION**：选一张模式卡
- **一眼看哪里**：`模式选择` 大标题 → 两张卡 ✓
- **可删**：无。
- **需要强调**：`竞技乱斗` 的副标题 `实时对战，吞掉最强对手！` 与 `无尽探索` 的 `无限地图，挑战更高分数！` 已经用暖色/蓝色区分 ✓
- **Panel 是否必要**：两张卡是核心，必要 ✓
- **Placeholder 感**：无——**卡内的预览是真实玩法截图**（`map_preview_arena` / `map_preview_city`），不是 AI 插图（符合 §30）
- **同一款游戏**：✓

### EndlessReady — 浅色（内部含深藏青药丸）
- **PRIMARY ACTION**：`开始探索 ▶`（金色，画面下部，最重）✓
- **一眼看哪里**：地图预览 → 金色 CTA ✓
- **可删**：无。
- **需要强调**：无。
- **Panel 是否必要**：地图预览卡 + 两条数据药丸（`历史最高纪录` / `当前机器`）都必要 ✓
- **Placeholder 感**：无
- **同一款游戏**：✓ —— **注意这一页内部同时有浅底卡片与深藏青药丸**，说明极性属于"表面"而非"页面"

### Pause — 浅色
- **PRIMARY ACTION**：`继续游戏`（金色，最大）
- **一眼看哪里**：`游戏暂停` 紫色标题 ✓
- **可删**：`当前进度已冻结` 是一句解释性文字。**信息价值低但不占地方**，保留（删除属于产品取舍，不在本轮）
- **需要强调**：`继续游戏` 已是最亮 ✓
- **Panel 是否必要**：浅紫卡片必要（承载三枚按钮）✓
- **Placeholder 感**：无
- **同一款游戏**：✓

### Settlement — 浅色
- **PRIMARY ACTION**：`再来一局`（金色）与 `返回首页`（紫）并列，主次清楚 ✓
- **一眼看哪里**：`本局结算` 标题 → 五行数据 ✓
- **可删**：无。五行（吞噬物品/最终质量/获得金币/最终等级/探索区域）都是本局真实数据
- **需要强调**：数值已用彩色（`0 kg` 紫、`LV.1` 蓝、`1` 绿）✓
- **Panel 是否必要**：是（§32 明确允许结算页占较大屏）
- **Placeholder 感**：无
- **同一款游戏**：✓

### Revive — 浅色
- **PRIMARY ACTION**：`立即复活`（金色）
- **一眼看哪里**：`复活继续` + 倒计时 `自动放弃倒计时 3s` ✓
- **可删**：无。`被 蓝莓 吞噬 · 对方 520 / 你 240 · 已击败 0 名对手` 是 V8.2 刚补的死亡原因，必须保留
- **需要强调**：倒计时红字已突出 ✓
- **Panel 是否必要**：是
- **Placeholder 感**：无
- **同一款游戏**：✓
- **备注**：本页的深红（`210,48,48` / `235,35,35`）**与 HUD 的 `255,92,92` 不同是正确的**——本页是浅底，HUD 是深底。已用稳定截图确认，不要再标为不一致。

### MachineInfo — 深色（只读页）
- **PRIMARY ACTION**：`返回首页`（唯一动作；本页刻意没有"升级"按钮，等级靠真实吞噬获得）✓
- **一眼看哪里**：`初级黑洞 · LV.1` 卡 + 三项当前能力 ✓
- **可删**：无。`下一等级：0 / 900 kg` 是成长目标，必要
- **需要强调**：5 行等级各自标注了 `当前使用` / `下一目标` / `未解锁` ✓（**目前只用文字，加颜色可一眼可扫——但前提是先确定本页是深色**）
- **Panel 是否必要**：是
- **Placeholder 感**：无
- **同一款游戏**：✓（深色页，与 HUD 同族）

### SkinSelection — 深色 · **需要动手（3 处低成本）**
- **PRIMARY ACTION**：`选择`（各行右侧按钮，按状态着色）✓
- **一眼看哪里**：顶部预览卡（黑洞外观 + 名称 + 描述）
- **可删**：**预览卡与第一行信息重复**——预览显示 `紫晶奇点 (默认)`，第一行也显示 `紫晶奇点 (默认) 已装备`。§28 明确问"什么信息可以删"。
- **需要强调**：已装备项已用紫色高亮 + `已装备` 标注 ✓
- **Panel 是否必要**：是
- **Placeholder 感**：**轻微**——5 行结构完全相同，靠色块区分，接近"重复条目"观感
- **同一款游戏**：✓

**三处低成本修正（按影响排序）**：

1. **`金币 0` 药丸压在预览卡上边缘**（右上角，一半在卡外）。应让预览卡为它留出位置，或把药丸移到标题行。
2. **预览卡与第一行重复**：`紫晶奇点 (默认)` 出现两次。建议列表行不再显示已选中项的名称，或预览卡只保留描述。
3. **行内色块贴卡片左边缘**（`SkinCard_*` 的色块紧贴卡片边框）。应留出内边距。

## 跨页一致性（§18「同一款游戏」）

- **金色 CTA 是统一的主操作色**：Home `开始吞噬` / Ready `开始探索` / Pause `继续游戏` / Revive `立即复活` / Settlement `再来一局` —— **五页一致** ✓
- **紫色是统一的次要操作色**：`结束本局` / `返回首页` / `结束并结算` ✓
- **品牌名 `黑洞回收站` 在每一页顶部中央**（备案要求）✓
- **标题药丸样式统一**（`模式选择` / `本局结算` / `引力核心皮肤` / `机器档案` / `复活继续`）—— 除 `机器档案` 是绿色药丸外，其余为紫色。**绿色是否为有意区分（机器页属"资料"类）需确认**，目前按有意处理。
- **极性**：6 页浅底、2 页深底（Machine / Skin）。**深底页与 HUD 同族**，浅底页自成一族。
