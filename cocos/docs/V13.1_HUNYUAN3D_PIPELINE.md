# 混元3D（腾讯）美术生产接入方案

日期：2026-10-20
位置：https://3d.hunyuan.tencent.com/sceneTo3D

## 一、已验证的界面事实（本机内置浏览器实测）

页面：腾讯混元3D·世界模型，四种模式（单选）：

| 模式 | 输入 | 输出 |
| --- | --- | --- |
| **世界生成** | 文字描述（textarea：`请描述你想要的3D场景...`） | 3D 场景 |
| **世界重建** | **图片上传**（`input[type=file]`，accept `.png,.jpg,.jpeg,.webp`）+ 文字 | 3D 场景 |
| 360°全景图 | 全景图 | 3D 场景 |
| 实时生世界 | — | 实时生成 |

顶部计分："20"（剩余额度/积分），"创作资产 1"。

**关键**：世界重建模式接受参考图上传 → 可以用七张设计图**直接驱动生成**，不靠文字转述。

## 二、与现有 Blender 管线的分工

| 用途 | 工具 | 理由 |
| --- | --- | --- |
| 街区/场景整体（Golden Arena） | **混元3D 世界生成/重建** | 一次出整体街区，人工建模不可能有这密度 |
| 单个可吞目标/载具/道具 | Blender（现有） | 需要精确控制 tier 尺寸与 pivot |
| UI 图标/头像/卡面 | SVG → Chromium 光栅化（现有） | 矢量、可改色、体积小 |

**不替换的部分**：`ObjectArtRegistry.unitScale()` 全绑定 1:1 的世界尺度体系；
unlit 渲染契约（换 standard 会让世界消失）。

## 三、执行约束（重要）

1. **生成一次需约 10–13 分钟**，且当前队列已有 1 个任务在跑。不能并行堆任务。
2. 生成结果需**人工确认可导出为 GLB/GLTF** 才能接入 Creator 资产库。
3. 生成的模型**必须过现有三道门禁**才能入库：
   - `glb_uv_tool.mjs inspect`（UV 非退化、有 TEXCOORD_0）
   - `review:model-quality`（贴地、pivot、尺度）
   - `review:level-composition`（不侵出生环/车道/视锥）
4. **授权**：混元3D 生成内容的商用许可需使用者自行确认，本方案只记录技术接入。

### 分工建议（不变）

混元3D → 整体街区/场景；Blender → 单体可吞目标与载具（精确 tier 尺寸/pivot）；
SVG → UI。混元3D **不适合**做可吞目标：它不保证 1.2–4.5 单位的建筑尺度、
不保证 pivot 居中、不保证贴地，而这三项 `ObjectArtRegistry` 全部依赖。
