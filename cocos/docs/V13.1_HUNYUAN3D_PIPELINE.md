## 二、与现有 Blender 管线的分工

| 用途 | 工具 | 理由 |
| --- | --- | --- |
| 街区/场景整体（Golden Arena） | **混元3D 世界生成/重建** | 一次出整体街区，人工建模不可能有这密度 |
| 单个可吞目标/载具/道具 | Blender（现有） | 需要精确控制 tier 尺寸与 pivot |
| UI 图标/头像/卡面 | SVG → Chromium 光栅化（现有） | 矢量、可改色、体积小 |

**不替换的部分**：`ObjectArtRegistry.unitScale()` 全绑定 1:1 的世界尺度体系；
unlit 渲染契约（换 standard 会让世界消失）。

## 三、执行约束（重要）

1. **生成一次需约 10–13 分钟**，且当前队列已有 1 个任务在跑。不能并行堆任务。
2. 生成结果需**人工确认可导出为 GLB/GLTF** 才能接入 Creator 资产库。
3. 生成的模型**必须过现有三道门禁**才能入库：
   - `glb_uv_tool.mjs inspect`（UV 非退化、有 TEXCOORD_0）
   - `review:model-quality`（贴地、pivot、尺度）
   - `review:level-composition`（不侵出生环/车道/视锥）
4. **授权**：混元3D 生成内容的商用许可需使用者自行确认，本方案只记录技术接入。

## 七、终局（2026-10-20，实际下载与判定）

三个文件已通过页面下载按钮取得（`art-source/references/hunyuan-output/`）。下载入口是 `.download-assets-select` 下拉，选项为 Splats(.spz) / Splats(.ply) / Collider mesh / 360° panorama；**没有 GLB**——这是 3DGS 世界生成，不是纹理网格生成。

### 7.1 Collider mesh：判废，不入库

`hunyuan-world-collider-mesh.ply`：815,977 顶点 / 1,560,142 面 / 逐顶点色 / **无 UV** / 28.3 × 23.9 × 10.2（Z-up，Open3D 导出）。

用 `scripts/render_hunyuan_mesh.py` 在 Blender 里渲三视图后判定（`artifacts/qa/hunyuan/mesh-*.png`）：

1. 它是**闭合的碗**——Poisson 重建把整个场景包成外壳，城市凹在里面；俯视是圆盘，外圈是重建壳不是地面。
2. 表面**径向拉丝 + 块状台阶**，街面糊成一片，没有可用的立面。
3. 右侧有全景接缝处的漂浮碎片。

要救它需要切壳 → 重拓扑 → 展 UV → 重贴图，而底子本身是糊的。**不作为游戏网格入库。**

### 7.2 Splats：不可渲染，仅离线参考

`hunyuan-world-splats.ply`：878,294 个高斯点（f_dc/opacity/scale/rot）。Cocos 3.8.3 没有泼溅渲染器，硬接要改渲染管线，而换 effect 会让整个 3D 世界消失。仅留作离线参考。

### 7.3 360° panorama：采用

`hunyuan-world-panorama-7680x3840.png`，7680×3840 等距柱状，2:1。低多边形商业街，与 DESIGN_07 视觉语言一致。

**已接入复活页背景**：`scripts/author_revive_city_backdrop.py` 裁 `x 3292..4388, y 1700..3648`（1096×1948，比例 0.5626 = 720:1280）→ 720×1280 JPEG q80（181,677 字节）→ `cocos/assets/game_art/ui/v95/revive_bg_city.jpg`，在 `RevivePage` 下插 `CityBackdrop`（`DimOverlay` 之前，alpha 保持 140 不变）。

三档截图见 `cocos/docs/evidence/v95/pages/revive-{375x667,390x844,430x932}.png`，均满幅无露边。微信主包 3.54 MB（限 4.00 MB），新图落在 `game-art` 分包。

### 7.4 3D 远景板：否决（几何上不可见）

审查代理的否决理由，已复核：

- 相机 `pitch=-55°`、垂直 `fov=44°`，**画面上缘光线 = -55+22 = -33°**，仍指向地面。相机高 44 → 上缘光线在水平 **67.7 m** 处与 y=0 相交。整幅画面都在地平线以下，**地平线与"地平线以上的城市带"永远不进画**。
- 圆柱要可见必须进 67.7 m；要避免相机穿出（相机随玩家最远可离场心 ≈67.8 m）半径又必须 ≥70 m。**两个约束无交集**：R≥70 的墙在上缘光线里位于地下，被地面与既有建筑完全遮挡。
- 缩小半径放进 67.7 m 内则必然切进 3×3 流送街区（`CELL_SIZE=64`、`ACTIVE_RADIUS=1`，覆盖 64–128 m）与竞技场自有道路/建筑，或落进出生环 11.8–16.2 的静态体禁区，直接撞 `review:level-composition`。
- 改 FOV/俯角让地平线入画已被实测击穿 LOCKED 构图四条带。

**唯一合法杠杆**是在真视锥内（上缘 x±14 / z −40.8..16.8）往 `Supermarket.prefab` 加 authored 剪影建筑——V13.1 已经这么做且过门禁。不要重提远景板。

### 7.5 大文件处理

- 两个 PLY（91 MB）与 32 MB 原始 PNG **不进 git**（`.gitignore` 已加规则），只留本地。原始 PNG 是唯一能全分辨率重裁的母版，混元额度一次性消耗，不删。
- 入库 `hunyuan-world-panorama-5120.jpg`（1,354,869 字节，5120×2560 q85）作为可重裁母版的提交副本：竖版取景窗占全景宽 14.27%，720 目标需要母版宽 ≥5040 px，5120 档下窗口 730 px，保住全质量余量；3840 档只有 548 px，不达标。
