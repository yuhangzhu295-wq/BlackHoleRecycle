## 3. 必须说清楚的三件事

1. **"一致"分两层**：**同类** vs **同图**。
   - **同类**（配色、黑洞画法、缎带语言、卡片语言）——**完全可以做到**，代价低。
   - **同图**（设计图那种插画密度与具体资产外观）——需要 hero 插画与资产重绘，
     能力已有，但是**工作量**，不是调参。

2. **竞技场是"同类"，不是"同图"**：现在是流式商业街区（SUPERMARKET），
   构图由程序决定，不会自己长成 DESIGN_07 那张手绘布局。要同图必须授权专门 cell。

3. **本文件没有把"结构一致"当成"视觉一致"**。逐页看下来，
   信息架构确实已经对上了——这正是为什么**不需要重建页面**；
   但配色、插画、黑洞画法、缎带语言这四项不改，画面就仍然不像设计图。
   这四项里有三项是低代价的。

## 4. 建议的执行顺序

1. 配色落地（#1）+ 黑洞统一画法（#2）——两项就能让全站立刻"像设计图那一族"
2. 缎带/卡片语言统一（#3）
3. hero 插画（#4）+ Mode 卡城市小景（#7）——复用既有 Blender 管线
4. Revive 信息块（#6）+ 结算行解剖（#5）
5. 竞技场专门 cell（#8）
6. 待你定：#9 磁吸/吸收加速是否暴露、#10 Home 是否加齿轮、#5 的称号文案
