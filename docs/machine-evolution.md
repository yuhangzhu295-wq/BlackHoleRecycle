# 《黑洞回收站》机器外观与性能进化规范 (Machine Evolution Spec)

## 1. 结构演进原则
机器进化是本游戏的核心爽感驱动力，每次进化必须同时发生**真实 3D 几何结构变化**、**发光光效强化**与**动力学能力暴增**，杜绝单纯改变数值的假升级。

## 2. 五大等级阶段详述
### LV1. Small Core (回收小车)
- **外观**：标准轻巧型蓝白清洁车底盘，配备四只橡胶车轮与中心黑洞视界井。
- **光效**：内圈弱青蓝旋转涡流，吸附半径指示圈。
- **能力**：吸附半径 2.4m，限吸 T1 物品，移速 7.5。

### LV2. Magnetic Turbine (吸附卡车)
- **外观**：底盘扩大 1.25 倍，车身两侧加装高转速旋转**双引力涡轮筒**。
- **光效**：涡轮边缘带荧光绿能量辉光，涡流速度加倍。
- **能力**：吸附半径 3.4m，限吸 T2 物品，移速 8.2，压缩效率 1.25x。

### LV3. Compression Engine (回收压路车)
- **外观**：重装卡车底盘扩大 1.55 倍，车尾加装**高压液压冲压机**与重型金属保险杠。
- **光效**：黑洞边缘环呈现金黄色高压能量环。
- **能力**：吸附半径 4.6m，可吞噬 T3 重型大纸箱与转椅，移速 9.0，压缩效率 1.6x。

### LV4. Gravity Harvester (巨型回收机)
- **外观**：重型双环底盘扩大 1.9 倍，两侧展开**双悬浮引力稳定翼**。
- **光效**：深紫霓虹光晕，释放环形引力波。
- **能力**：吸附半径 6.0m，可吞噬 T4 沙发、双门冰箱与水泥管，移速 9.8，压缩效率 2.0x。

### LV5. Singularity Core (歼星奇点车)
- **外观**：终极奇点底盘扩大 2.3 倍，车体上方悬浮**天体奇点白色光环 (Singularity Halo)**。
- **光效**：全屏白热能量粒子与极端引力透镜动态效果。
- **能力**：吸附半径 8.0m，可吞噬 T5 报废汽车、叉车与巨型集装箱，移速 10.5，压缩效率 2.8x。
