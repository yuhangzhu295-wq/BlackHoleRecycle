# 《黑洞回收站》游戏设计文档 (Game Design Document)

## 1. 游戏定位与核心概念
- **游戏名称**：《黑洞回收站》（英文名：BlackHoleRecycle，副标题/设计名：《压个痛快》）
- **宣传语**：吸走一切，压个痛快！
- **游戏类型**：3D 无尽吸附解压休闲小游戏 (Hyper Casual 3D Suction & Recycling)
- **目标平台**：微信小游戏、抖音小游戏、Web 现代浏览器
- **屏幕方向**：9:16 Portrait 竖屏沉浸体验
- **核心操作**：单指触屏拖动 / 虚拟摇杆 / PC WASD 键盘控制

## 2. 核心游戏循环 (Core Gameplay Loop)
```
  [移动黑洞吸尘机] ──> [靠近场景废弃杂物] ──> [自动引力吸附与吞噬]
         │                                       │
         ▼                                       ▼
  [累积真实质量 Mass] <────────────────── [获得积分与动态连击 Combo]
         │
         ├──> [达成进化阈值] ──> [机器 5 级真实 3D 外观与性能进化] ──> [吞噬更大物体]
         │
         ├──> [达成清理进度] ──> [无尽地图无缝 Chunk 滚动 / 解锁新区域]
         │
         └──> [进入压缩缓存] ──> [液压机械压缩装车] ──> [产出金币 🪙] ──> [永久属性强化 & 皮肤]
```

## 3. 核心机制详解
### 3.1 引力吸附与吞噬系统 (Suction & Physics)
- 物体状态机：`IDLE`（静止） ➔ `ATTRACTED`（受引力吸引） ➔ `SUCKING`（螺旋下潜缩小） ➔ `ABSORBED`（吞噬完成入池）。
- 物理开销优化：在进入吸附半径后，通过程序化贝塞尔螺旋与切向旋转曲线控制物体飞向黑洞中心，兼顾丝滑吞噬感与低端机 60FPS 帧率。
- 物体 Tier 限制：机器 `maxTier` 限制可吞噬的物体级别。等级不足时显示 `🔒 需升级` 锁标。

### 3.3 爽感技能系统 (Active Skills)
1. **🧲 磁暴模式 (Magnet Storm)**：释放全屏强引力波，吸附半径扩大 1.8 倍，引力速度翻倍，瞬间吸入全场散落杂物。
2. **⚡ 疾速推进 (Speed Boost)**：黑洞机器移速提升 60%，车轮飞转并带动态倾角运动。
3. **📦 即时压缩 (Instant Compression)**：立即将当前缓冲区全部质量压成高密资源块并召唤卡车运走，获得大量金币。

### 3.4 局内 Roguelike 三选一强化
在质量达到里程碑时弹出强化选择（如吸力提升 +20%、移动速度 +15%、压缩效率 +25%、磁暴延长 +3s 等），支持金币与看广告免费刷新。
