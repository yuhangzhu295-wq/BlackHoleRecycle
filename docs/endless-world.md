# 《黑洞回收站》无尽分块流式世界系统 (Endless Chunk Streaming)

## 1. 架构原理
为保证玩家在持续前进中获得无边界的世界探索体验，同时将移动端内存与 DrawCall 严格控制在安全阈值，游戏采用 `WorldChunkManager` 流式分块加载架构：

```
[Previous Chunk]  <───  [Current Chunk (玩家所在)]  ───>  [Next Chunk]  ───>  [Next+1 Chunk]
 (身后远离时回收入池)            (实时更新物体引力)           (预加载地表网格)      (预先分布物体)
```

## 2. 六大主题分块配置
1. **Bedroom (卧室杂物区)**：
   - 地表暖色木地板，散落易拉罐、矿泉水瓶、纸团、袜子、电池等 T1~T2 物品。
2. **Warehouse (仓库区)**：
   - 工业深灰地表，堆叠高耸货架、重型瓦楞纸箱、木质货箱、电脑椅、微波炉。
3. **Supermarket (超市区)**：
   - 绿色瓷砖地表，散落饮料塔、推车商品盒、托盘货物。
4. **Parking (停车场)**：
   - 沥青路面、路锥、轮胎、路障与报废轿车。
5. **Construction (工地区)**：
   - 沙黄泥土地表，水泥管、砖块堆、大型机械残骸。
6. **City (城市区)**：
   - 现代街道、长椅、路灯杆、巨型集装箱与整个建筑结构。

## 3. 对象池 (ObjectPool) 复用机制
- 所有可吸附物品 `TrashObject`、地表网格与粒子对象均纳入全局对象池管理。
- 远离视锥体与玩家身后 1.5 个 Chunk 长度的物体自动回收入池，彻底杜绝高频 Instantiate / Destroy 带来的 GC 卡顿。
